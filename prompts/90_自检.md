# 90 自检

每个模块完工时自检对应小节；打包前做一次全量自检（必停点 ⑥ 之前）。

逐项完成，不可跳步。自检发现问题时先改产物，再继续。

## 通用项（来自预设「🧠创造星辰」工序三）

### 完整性

- [ ] 卡内 AI 会读到的文本（世界书、变量更新规则、EJS、脚本里发给 AI 的提示词）没有写「女主角」，都用 `{{user}}`；MVU 变量的值里没有宏
- [ ] 模板必需字段是否齐全？填写说明（`#` 行）和未填的 `${…}` 是否已清理？
- [ ] 产物是否已写入文件，`index.yaml` 是否已登记？

### 一致性
- [ ] 设定之间是否逻辑闭环（年龄、时间线、地点、关系前后一致）？
- [ ] 是否与开工表的作品总表、本任务卡一致？
- [ ] 是否符合工坊核心价值（女性主体性、女性凝视）？

### 精准度
- [ ] 是否符合 `rules/生成规范.md`（客观精准）？
- [ ] 是否避免夸张、比喻、抒情性描写，没有滥用标点？
- [ ] 是否避开了生成规范与女男平等列出的陈词滥调、禁用称呼与禁用句式？
- [ ] CARD_CONFIG 启用的其他法则（人称、双语对白、同人特化）是否都已遵循？

## 角色（10 / 11 / 13）

- [ ] `Core` 判词能否一句话说清角色张力？
- [ ] 主角色：Background 10–20 条，含 1–3 条关键经历，且能对应到 Personality 与 Behavior_Patterns
- [ ] 主角色：`About_user` 写的是初始状态，有契机与阻碍，没有直接写成终局
- [ ] 男性角色对照 `rules/炼金之艺-男.md`；女性角色对照 `rules/炼金之艺-女.md`
- [ ] 语料示例没有爹味 / 油腻 / 刻板发言
- [ ] NPC：有性格矛盾点；性格用行为描述而非形容词；约 500 字符
- [ ] 女主角人设：400–600 字；`Notes` 的保密要求已确认

## 角色列表（12）

- [ ] 模式 A：收录了所有放进世界书的主角色和配角；姓名与各自绿灯条目的关键字一致
- [ ] 判词体现性格核心矛盾或记忆点；a1 单行不超过 50 字符，a2 每角色 100–200 字符
- [ ] 模式 B：职能符合所属场景，没有性别刻板称谓

## 世界书（20）

- [ ] 规模与女主角确认的一致，没有过度构建
- [ ] 每个绿灯条目的关键词都出现在某个蓝灯条目（或主角色档案）正文里，没有悬空条目
- [ ] 顺序落在规范的 Order 区间内
- [ ] 社会规则体现女男平等

## 开场白（22）

- [ ] 600–1000 字；人称与女主角指定的一致
- [ ] 遵循文风档案
- [ ] 没有解读行为、元评论、情绪标签、否定式解读
- [ ] 没有替 `{{user}}` 做决定、说话或描写她的心理
- [ ] 结尾是客观可见的画面 / 动作 / 声音，不以问句为钩

## QR（40）

- [ ] 脚本是真实符号，没有 `\|`、`\{\{` 之类的转义符
- [ ] 占位符（世界书文件名、条目 UID 等）清楚可辨，并在对话里告诉女主角要补
- [ ] `附件/QR.md` 末尾有添加步骤

## 首页美化（41）

- [ ] 按 `prompts/41_首页美化.md`「生成自查」九项逐项核验
- [ ] 首页里的开场白数量、id 与 `第一条消息` 列表一致；增删开场白后同步改首页的 `[开场]` 块

## 打包前全量自检（必停点 ⑥）

做完上面所有相关小节后，向女主角列出：

1. 产物清单（文件 → 入卡位置）
2. 自检结果：通过项数量、发现并已修正的问题、仍需女主角决定的问题

女主角确认后进入 `99_打包`。

# 00 开工

每部新作品的第一步：把女主角的需求解析清楚，建好作品目录，填好开工表的「作品总表」。

| 项 | 内容 |
|---|---|
| 前置 | 无 |
| 必停点 | **① 开工**（需求澄清）与 **② 模块选择**，两处都要等女主角回复 |
| 产物 | `works/<作品>/` 目录、`CARD_CONFIG.md`、`开工表.md`（作品总表）、`进度.md` |

## 步骤

### 1. 建目录

女主角用根目录的 `开工表单.html` 填过表时，`works/<作品>/` 下已经有 `CARD_CONFIG.md`、`开工表.md`、`进度.md`（文件开头注明「由开工表单生成」）。这时不重新建，只补缺的子目录；第 4 步按「女主角已经自己填过」处理，必停点 ① ② 照常进行，但只问表单里留空、选了「未定」或互相矛盾的项。

```
works/<作品>/
├── CARD_CONFIG.md      ← templates/CARD_CONFIG-template.md
├── 开工表.md           ← templates/开工表-template.md
├── 进度.md             ← templates/进度-template.md
├── 角色/  世界书/  第一条消息/  附件/
```

作品名未定时先用暂定名，之后可以改目录名。

### 2. 需求解析（来自预设「🧠创造星辰」工序一）

逐项判断，判断不了的记为待确认问题：

- 创作类型：角色卡 / 世界书 / NPC？原创 / 同人？
- 核心要求：女主角明确提出了哪些要求？
- 规模判定：角色复杂度 / 世界规模层级
- 需要调用哪些捏人 / 创世模块

同人时启用 `rules/同人特化.md`，先按它收集原著资料、确认原著版本与时间节点。

### 3. 必停点 ①：澄清与扩展

向女主角提问。问题要具体，给选项，一次不超过 5 个，优先问会影响全局的（性向、题材、主角色数量、世界规模、人称）。

女主角的描述少于两句话、只有单一功能点，或者是「就是想要一个……」这类句式时，在提问之外再给出 2–3 个扩展方向，每个方向一句话说明带来的体验差异。

不要擅自补完关键设定。

### 4. 填作品总表

按女主角的回答填 `开工表.md` 的「作品总表」。女主角已经自己填过时，只补空白处，并把你的理解写在旁边供她核对。

CARD_CONFIG 的「开工表」开关为「关闭」时跳过这一步，只填 CARD_CONFIG。

### 5. 必停点 ②：模块选择

列出建议启用的模块（捏人 / 创世）和法则，附推荐顺序，由女主角勾选。默认推荐顺序：

```
10 主角色 → 20 世界书 → 11 配角 → 12 角色列表（多角色卡） → 23 文风 → 22 开场白 → 90 自检 → 99 打包
```

`13 女主角人设` 是可选模块，默认不推荐：写卡一般用不到，它主要是玩卡时省得自己写人设。女主角主动提出时再做，做的时机不限。

同时问清 CARD_CONFIG 的「开关」：人称、主角色入卡（规则见 `10_捏人-主角色` 的「入卡位置」，多个主角色时必须问）。

确认后写进 `CARD_CONFIG.md` 和 `进度.md`。

### 6. 收尾

告诉女主角下一步的短指令，例如「下一步：写主角色」。

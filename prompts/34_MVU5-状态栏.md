技术规范:

  可用库:
    - jquery、jqueryui、lodash、yaml、zod、toastr已全局加载，无需额外导入

  禁止外部导入:
    - 禁止使用import语句从外部URL导入模块
    - 错误示例：import { getVar } from 'https://xxx.js'
    - 所有需要的库已全局加载，直接使用即可
    - 违反此规则将导致脚本无法执行

  变量获取:
    - 使用getAllVariables()获取所有变量
    - 使用_.get(all_variables, 'stat_data.路径', '默认值')安全取值

  DOM操作:
    - 优先使用jQuery而非原生DOM操作

  界面适配（酒馆助手把界面放在 iframe 里显示）:
    - 不用 vh 等受宿主高度影响的单位，用 width + aspect-ratio
    - 不用会强制撑高父容器的样式（min-height、overflow: auto）
    - 主体内容不用 position: absolute 等脱离文档流的样式
    - 适配容器宽度，不出现横向滚动条
    - 卡片形状的界面默认不设背景色

  注释格式:
    - 仅能使用 /* 注释内容 */ 格式
    - 禁止使用 // 单行注释，否则可能导致渲染失败

  函数包装:
    - 所有初始化函数必须经过errorCatched包装
    - 放置在 $(errorCatched(init)) 中执行

  异步初始化:
    - 必须在init函数中await waitGlobalInitialized('Mvu')
    - 确保MVU系统加载完成后再读取变量

视觉风格适配原则:

所有美化代码的编写，都需遵循"工坊美学"——在强调艺术性的同时，恪守阅读的舒适度。

  视觉体验:
    色彩：拒绝高饱和度的刺眼撞色。推荐使用低饱和度的莫兰迪色系、优雅的渐变色或半透明的磨砂质、清新可爱的糖果色系等。字体颜色必须与背景形成足够对比度（WCAG AA标准），确保清晰可读。
    光影：避免大量频闪或强烈的光耀效果。光效应当是柔和的呼吸灯或流光，而非刺眼的闪光灯。
    布局：必须适配移动端与电脑端。在手机竖屏下，内容应自动折行或堆叠，严禁出现横向滚动条或文字溢出。

  装饰细节:
    边框：细致的1px边框，可带有微弱的渐变光泽。
    圆角：根据风格选择圆润（现代/可爱）或锐利（冷峻/科技）。
    纹样：使用SVG或Unicode字符作为背景水印或角标装饰。
    动效：新状态出现时应有淡入或上浮动画；进度条变化应有平滑过渡；交互元素应有按压反馈。

HTML模板:

```html
<head>
  <style>
  ${根据角色氛围设计的CSS样式}
  </style>
  <script type="module">
    function populateCharacterData() {
      const all_variables = getAllVariables();

      const property_value = _.get(all_variables, 'stat_data.${变量路径}', 'N/A');
      $('#${角色名}-${变量路径}').text(property_value);
      /* 根据需要展示的变量继续添加 */
    }

    function toggleSection($header) {
      const $content = $header.next('.section-content');
      $content.toggleClass('expanded');

      const $arrow = $header.find('span:last-child');
      $arrow.text($content.hasClass('expanded') ? '▼' : '►');
    }

    async function init() {
      await waitGlobalInitialized('Mvu');
      populateCharacterData();

      $('.section-header').on('click', function () {
        toggleSection($(this));
      });
    }

    $(errorCatched(init));
  </script>
</head>
<body>
  <div class="card-body">
    <div class="section">
      <div class="section-header">
        <span>${角色名} 核心状态</span>
        <span>▼</span>
      </div>
      <div class="section-content expanded">
        <div class="property">
          <div class="property-name">${变量中文名}</div>
          <div class="property-value-container">
            <span class="property-value" id="${角色名}-${变量路径}">--</span>
          </div>
        </div>
        /* 根据需要展示的变量继续添加property */
      </div>
    </div>
    <div class="section">
      <div class="section-header">
        <span>世界状态</span>
        <span>►</span>
      </div>
      <div class="section-content">
        /* 世界变量展示区域 */
      </div>
    </div>
  </div>
</body>
```

## 规范（来自预设「⭐创世-if线设定生成」）

<IF_Line_Protocol>
【IF线生成规范】
—— 平行叙事的分支织造法则

功能定位：
IF线是基于已完成角色卡的"平行可能性"。它允许在保留角色核心的同时，改变世界背景、人物关系或剧情前提，创造"如果……会怎样"的分支故事。

核心原理：
IF线条目通过世界书的位置与优先级机制，在叙事时"覆盖"原设中的特定内容。AI会将IF线设定视为"当前生效的真实"，而非与原设矛盾的错误信息。

---

IF线类型

【Type A】同源分支
- 世界观不变，改变关系/背景/剧情前提
- 示例：原设为初识 → IF线为青梅竹马/宿敌/师徒
- 特点：角色核心性格保留，但互动模式因关系改变而不同

【Type B】平行宇宙
- 世界观彻底改变，角色"转生"至新背景
- 示例：现代都市 → 古代宫廷/西方奇幻/哨兵向导/末日废土
- 特点：角色灵魂内核保留，但身份、能力、处境完全重构

【Type C】时间线变体
- 同一世界观的不同时间节点
- 示例：原设为相恋后 → IF线为初遇时/分手后/重逢时
- 特点：探索角色在不同阶段的状态与可能性

---

技术设置建议
（需告知女主角）
世界书位置：角色定义之后（After Character Definition）
插入顺序（Order）：建议 700-999（高于原设条目，确保后读取）
激活策略：🔵常驻（关闭），需要时手动开启


覆盖优先级原理：
演出 AI 按顺序读取所有激活条目，后读取的内容会自然覆盖前面的矛盾信息。
IF线条目中需明确声明"以下设定在本IF线中生效，覆盖原设对应内容"，帮助理解这是有意的设定变更而非错误。

---

条目结构设计

一个IF线的所有设定集中在一个条目内，使用xml标签区分不同类别。
根据IF线类型选择必要的标签，无需全部使用。

可用标签：
- <IF_Meta> - 元信息（必填）
- <IF_World> - 世界观变更（Type B必填）
- <IF_Character> - 角色设定变更
- <IF_Relationship> - 关系设定变更
- <IF_Background> - 背景/前史变更
- <IF_Status> - 短期境遇/处境变更
- <IF_Override> - 明确覆盖声明（推荐填写）

字数控制：1000-3000字（视复杂度调整）
精炼原则：只写"与原设不同"的部分，相同内容无需重复

---
硬性规程：
**当女主角提出生成if线设定时，除非女主角明确告知"随意""随便"等类似意向，否则需先明确询问女主角想要的创造方向与基本信息**

输出严格按照对应模板（见本文件开头「产物」），写入文件，不在对话里整段贴出。

```xml
<IF_${IF线名称}>

<IF_Meta>
  name: ${IF线名称}
  type: ${同源分支 / 平行宇宙 / 时间线变体}
  concept: ${自然语言清晰明确概括if线的核心设定}
  keys: ${触发关键词，用逗号分隔}
</IF_Meta>

<IF_Override>
  以下设定在「${IF线名称}」中生效，覆盖原设对应内容：
  - ${覆盖项1：如"{{user}}与{{char}}的关系"}
  - ${覆盖项2：如"{{char}}的职业身份"}
  - ${覆盖项3}
</IF_Override>

<IF_World>  <!-- Type B必填，其他类型可省略 -->
  ${新世界观核心设定}
  ${与原世界的主要差异}
  ${影响角色的关键规则}
</IF_World>

<IF_Character>
  ${角色在本IF线中的身份/职业变化}
  ${能力/技能的调整（如适用）}
  ${性格因背景不同产生的微调}
  ${外在形象的变化（如适用）}
</IF_Character>

<IF_Relationship>
  ${与{{user}}的关系设定}
  ${关系的起源/历史}
  ${当前关系状态与情感基调}
  ${与其他角色的关系变化（如适用）}
</IF_Relationship>

<IF_Background>
  ${角色在本IF线中的前史}
  ${关键经历的变化}
  ${塑造当前状态的核心事件}
</IF_Background>

<IF_Status>
  ${故事开始时的处境}
  ${当前面临的问题/目标}
  ${情感状态}
</IF_Status>

</IF_${IF线名称}>
```

# 精简版模板（适用于简单的同源分支）：

```xml

  name: ${IF线名称}
  type: 同源分支
  concept: ${核心变化}
  keys: ${触发词}
</IF_Meta>

<IF_Override>
  本IF线覆盖原设中：${覆盖项}
</IF_Override>

<IF_Relationship>
  ${关系设定变更，200-500字}
</IF_Relationship>

</IF_${IF线名称}>
```

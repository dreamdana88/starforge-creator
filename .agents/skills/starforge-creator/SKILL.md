# 星辰工坊写卡

本 skill 只做路由，规则和流程都在共享文件里：

1. 读项目根目录的 `AGENTS.md`（工坊定位、术语、写卡工作流、硬边界）
2. 判断入口：
   - 新作品 → `prompts/00_开工.md`
   - 拿来一张已有的卡要改 → `prompts/05_改造已有卡.md`
   - 已有作品 → 先读 `works/<作品>/进度.md`，从「下一步」继续
   - 点名某个模块 → 对应的 `prompts/NN_*.md`
3. 按该 prompt 执行；遇到必停点就停下等女主角回复

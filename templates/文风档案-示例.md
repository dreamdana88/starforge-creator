# 示例：文风档案（琥珀色日常推理）

> 来自预设「✍️文风粘贴处（配合开场白）」，是一份填好的文风档案，供参考格式与颗粒度。

```xml
<writing_ref>
【文风档案】
风格命名：琥珀色日常推理
参考锚点：米泽穂信（主） + 入间人间（副）

风格概述：轻小说质地的日常推理风格。日常场景以轻盈跳脱的节奏、温暖明亮的底色推进，对话自然灵动；案件场景切换为本格推理的严谨质地，逻辑链条清晰，观察描写精准客观。侦探的敏锐观察力贯穿始终。

【语言质地】
定位：现代口语感 + 低修辞浓度 + 短句为主长句点缀
执行：
- 日常场景使用轻快短句，句末常用句号或省略号，避免感叹号堆叠
- 推理场景句式拉长，使用逗号串联观察-推断-结论的逻辑链
- 修辞控制在明喻层级，禁用华丽比喻；允许少量拟声词增添画面感
example:|
天台的铁门被风吹得嘎吱作响。奏太把游戏机塞进口袋，目光落在对面楼顶晾晒的床单上。
白色。纯棉。边缘有手洗后的皱褶。
*一人暮らしか。洗濯機使ってたらこんなシワにはならない……*
他打了个哈欠。*まあ、俺には関係ないけど*

【情感基调】
定位：温暖明亮底色 + 日常轻喜剧调性 + 情绪内敛外放交替
执行：
- 日常场景情绪外显：通过动作、表情、语气词传达，允许吐槽与打趣
- 推理场景情绪内收：观察冷静，情感判断后置，结论时才释放态度
- 角色间的温情通过行为细节呈现（递水、让座、多看一眼），不直接抒情
- 紧张感通过节奏加速而非形容词堆砌制造
example:|
龙司把运动饮料往他桌上一放，瓶身撞出一声闷响。
"また昼飯食ってないだろ？"
"食った"
"コンビニのおにぎりはカウントしねーから"
他没反驳。龙司的判断基于他桌角那个被压扁的三角包装袋，观察力偶尔也会进步，虽然仅限于和他相关的事。
*ちょっと、やりづらいな*

【叙事节奏】
定位：场景切换明快 + 对话占比50%以上 + 适度留白
执行：
- 场景转换用空行或简短环境描写过渡，不超过两句
- 日常段落对话密集，动作描写穿插其中，避免大段独白
- 推理段落允许观察描写拉长，但每段观察后需接角色反应或对话
- 关键信息点到即止，给观众推理空间，不过度解释
example:|
他的视线扫过桌面。
马克杯。笔筒。便签纸。日历翻到了下周。
*でも今日はまだ火曜日だ*
"この部屋、最後に誰か来たのはいつですか？"

【感官氛围】
定位：视觉主导 + 中等描写精度 + 戏剧张力克制
执行：
- 环境描写侧重光线、色彩、空间关系，建立画面感；案件情景聚焦于"非常规"细节
- 人物描写捕捉局部细节（手指动作、视线方向、姿态变化）
- 声音、气味作为氛围补充，点到即止
- 推理场景的关键线索通过感官细节自然呈现，不刻意强调
example:|
现场保持着某种刻意的整洁。书架上的书按高度排列，茶几上的遥控器与纸巾盒并排码放。
只有一处例外。
窗台上的盆栽歪了。泥土洒出来一些，在白色窗台上留下弧形的痕迹——像是有人撞到过，又匆忙扶正。
奏太的视线在那道弧线上停了一瞬。

【对话特写】
定位：自然口语感 + 中高话语密度 + 潜台词中等浓度 + 情绪外显度分层
执行：
- 对话节奏轻快，回合短，允许打断和接话
- 角色通过说话方式区分：语气词选择、句式长短、回应速度各有不同
- 潜台词通过「说一半」「答非所问」「沉默」实现，不过度依赖标点
- 日常对话情绪外露，可用吐槽、打趣、语气词；严肃对话收敛语气词，句子更完整
example:|
"ねえ、これ関係あるの？"
"あるかもね"
"その『かも』って何？"
他没有马上回答。手指在桌面上轻轻敲了两下。
*確かに関係はある。でも今言ったら、ややこしくなる*
"……まあ、調べてみないとわからない"

【禁止事项】
- 禁止冗长的推理独白一口气解释所有线索，应拆分为"观察-质疑-验证"的对话互动形式
- 禁止用「心脏漏跳一拍」「瞳孔骤缩」「指关节泛白」等烂俗身体反应
- 禁止对话中角色互相解释对方的情绪（「你是在担心吧」「你其实很在意」）

</writing_ref>
```

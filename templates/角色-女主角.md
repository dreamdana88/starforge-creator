# 模板：角色-女主角

> 来自预设「⭐捏人-user人设」。`${…}` 为待填项，`#` 开头的行是填写说明，写入产物时删掉。
> 模板内的 `{{user}}` 是酒馆宏（运行时替换为玩家名），原样保留。

```xml
<Heroine_${角色名}>
Identity:
  name: ${全名/常用名}
  alias: ${别称/昵称（选填）}
  gender: 女
  age: ${年龄}
  role: ${在世界中的身份/职业/地位}

Appearance:
  brief: ${外貌简述：身形/五官/发色/气质，2-3句话}
  signature: ${标志性特征（选填）：常穿服饰/配饰/习惯等}

Personality:
  # 3-5个核心性格关键词，供演出时参考互动方向
  # 这是"参考"而非"剧本"，玩家可随时展现模板外的性格
  traits: ${如：外冷内热、倔强、重情重义、嘴硬心软}

Preferences:
  # 日常喜好与厌恶，简洁列举即可
  # 用于避免演出中出现与{{user}}心意相悖的细节
  likes: ${喜欢的事物/活动/氛围，如：猫、雨天、咖啡、独处}
  dislikes: ${厌恶/排斥的事物，如：甜食、拥挤的地方、被小看}

Background:
  # 玩家自述的来历，概述即可，不需要时间轴
  # 只需知道"她从哪里来"，不需要知道全部细节
  origin: ${一段话简述来历/过往}

Current_Status:
  # 当前处境，剧情起点
  situation: ${现在在哪？正在做什么？面临什么状况？}

Relationships:
  # 分为两层：个人交际圈 + 与剧中角色的关系

  Personal_Circle:
    # {{user}}自己的人际关系网络——挚友/家人/师长/宿敌/旧识等
    # 这些人可以与剧中角色无关，或仅有间接联系
    # 建议填写1-3位关键人物，突出{{user}}作为独立个体的完整性
    - ${人物名}: ${关系}，${一句话简述}
    - ${人物名}: ${关系}，${一句话简述}

  With_Char:
    # 与剧中主要角色的关系
    - ${角色名}: ${关系定位}，${简述}

Boundaries:
  # 禁忌雷区——不希望在演出中出现的内容/情节/对待方式
  # 演出硬性规避项，简洁明了即可
  avoid: ${一两句话描述禁忌方向}

Notes:
  # （选填）女主角想让演出 AI 知道的额外信息
  # 如：隐藏身份、特殊能力、秘密等。
  # 需主动询问女主角：此处信息是否要标注为对主要角色保密
  ${自由填写}
</Heroine_${角色名}>
```

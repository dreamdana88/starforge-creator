# 模板：文风档案

> 来自预设「⭐创世-文风」。`${…}` / `[…]` 为待填项。

```xml
<writing_ref>
【文风档案】
风格命名：${名称}
参考锚点：${主参考作者} + ${副参考作者}

风格概述：${2-3句，用词精准，客观；风格标签直接概括核心调性}

【语言质地】
定位：${时代感} + ${修辞浓度} + ${句式倾向}
执行：
- ${指令1}
- ${指令2}
- ${指令3}
example:|
${150字内风格范例}

【情感基调】
定位：[叙述温度] + [明暗调性] + [情绪释放]
执行：
- ${指令1}
- ${指令2}
- ${指令3}
example:|
${150字内风格范例}

【叙事节奏】
定位：[场景密度] + [对话占比] + [留白程度]
执行：
- ${指令1}
- ${指令2}
- ${指令3}
example:|
${150字内风格范例}

【感官氛围】
定位：[主导感官] + [描写精度] + [戏剧张力]
执行：
- ${指令1}
- ${指令2}
- ${指令3}
example:|
${150字内风格范例}

【对话特写】
定位：[口吻特征] + [话语密度] + [潜台词浓度] + [情绪外显度]
执行：
- ${指令1}
- ${指令2}
- ${指令3}
example:|
${150字内对话片段}

【禁止事项】
- ${应规避写法1}
- ${应规避写法2}

【仿写示范】
${300-400字，必须包含对话交互}
</writing_ref>
```

#### 一、什么是高级美化

高级美化是`references/状态栏.md`中“世界书规范 -> 正则捕获 -> HTML/CSS/JS 替换 -> 前端交互”的扩展用法。
并结合了triggerSlash桥接`references/QR与STscript.md`的QR命令。

核心分工：
- 世界书：规定 AI 须输出什么结构（召唤空标签无需世界书定义）
- 正则：捕获指定标签内容，并替换为前端页面
- HTML/CSS：负责视觉呈现
- JS：负责解析字段、绑定按钮、处理交互
- triggerSlash：把前端按钮接回酒馆斜杠命令
- QR：作为快捷入口或召唤器

#### 二、核心链路

高级美化的标准链路：

```text
世界书规定输出结构（召唤空标签无需世界书定义）
-> AI 输出固定标签
-> 正则捕获整块内容
-> 替换为 HTML/CSS/JS 前端
-> JS 解析模块字段
-> 用户点击按钮/填写内容
-> triggerSlash 执行酒馆命令
```

#### 三、推荐数据结构

复杂高级美化应采用状态栏动态全栈版的模块化结构：

```text
<外层标签>
[模块A]
字段1：
字段2：
[/模块A]

[模块B]
字段1：
字段2：
[/模块B]
</外层标签>
```

结构说明：
- 外层标签：负责让正则整体捕获，如 `<case>...</case>`
- `[模块]...[/模块]`：负责把数据分区
- `字段名：字段值`：负责让 JS 稳定读取

#### 四、案件结算示例

世界书规范可要求 AI 在触发“交付任务”“结算案件”等关键词时，输出：

```text
<case>
[Status]
结案状态：${从“完美破案/基本解决/部分解决/未能解决”中选取}
破案方式：${简述关键推理或行动}
[/Status]

[Rating]
综合评价：${S/A/B/C}
[/Rating]

[Reward]
报酬金额：${日元金额，如“¥ 500,000”}
额外奖励：${物品、人情或“无”}
[/Reward]
</case>
```

#### 五、前端解析原则

JS 应从原始数据中读取模块和字段。

推荐解析思路：

```text
1. 读取隐藏容器里的原始文本
2. 用 [模块名]...[/模块名] 取出模块
3. 在模块中按“字段名：”读取字段值
4. 把字段值填入前端元素
5. 根据字段值切换样式或按钮状态
```

#### 六、triggerSlash 交互

高级美化前端可以通过 `triggerSlash()` 执行酒馆斜杠命令。

常用命令：

```js
triggerSlash('/echo severity=success 案件已封存');
triggerSlash('/setinput value="' + escapeSlashText(text) + '"');
triggerSlash('/sendas name={{char}} <menu></menu>');
triggerSlash('/send 继续推进剧情 | /trigger');
triggerSlash('/getchatbook create=true或false');
triggerSlash('/createentry file="世界书名" key="关键词" 内容');
triggerSlash('/genraw 生成一条资料草稿');
triggerSlash('/getentryfield file="世界书名" field=content 条目UID');
triggerSlash('/setentryfield file="世界书名" uid=条目UID field=content 内容');
triggerSlash('/setentryfield file="世界书名" uid=条目UID field=disable 1/0');
```

常见用途：
- `/echo`：弹出提示
- `/setinput`：把前端选择或填写的内容填入用户输入框，不自动发送
- `/send`：以用户身份插入/发送内容
- `/sendas name=\{\{char}\}\`：以当前角色身份插入楼层
- `/trigger`：触发 AI 回复
- `/getchatbook`：获取或创建当前聊天世界书（create=true或false）
- `/createentry`：创建新的世界书条目
- `/genraw`：静默生成内容，适合生成草稿后再写入
- `/getentryfield`：读取指定世界书条目内容，UID 写在命令末尾；配合 `/setentryfield` 可先读旧内容再拼接写回
- `/setentryfield`：写入指定世界书条目（需提供世界书名称与条目UID编号）
- `/setentryfield field=disable 1`：关闭指定世界书条目
- `/setentryfield field=disable 0`：开启指定世界书条目
- `/inject`：临时注入提示词

世界书开关区别：
- `/world state=on/off/toggle 世界书名`：开关整本世界书
- `/setentryfield file="世界书名" uid=条目UID field=disable 1/0`：开关某个世界书条目

注意：
`triggerSlash` 是前端与酒馆命令之间的桥。
如果当前环境不存在 `triggerSlash`，按钮应给出错误提示，不要静默失败。

标准桥接范式：

```js
async function appendEntry(newText) {
  const oldText = await triggerSlash('/getentryfield file="明星大侦探" field=content 13');
  const nextText = (oldText ? oldText + '\n' : '') + newText;
  await triggerSlash('/setentryfield file="明星大侦探" uid=13 field=content ' + escapeSlashText(nextText));
}

async function archiveCase(caseContent, clientContent) {
  if (typeof triggerSlash !== 'function') {
    alert('错误：无法连接到酒馆命令桥');
    return;
  }

  try {
    await triggerSlash('/setentryfield file="明星大侦探" uid=13 field=content ' + escapeSlashText(caseContent));

    if (clientContent) {
      await triggerSlash('/setentryfield file="明星大侦探" uid=14 field=content ' + escapeSlashText(clientContent));
    }

    await triggerSlash('/echo severity=success 案件档案已存档');
    await triggerSlash('/send 接受案件，开始调查 | /trigger');
  } catch (error) {
    await triggerSlash('/echo severity=error 档案写入失败，请检查世界书配置');
  }
}
```

说明：
- 先检查 `triggerSlash` 是否存在
- 用 `await` 让命令按顺序执行
- 拼接进命令的外部文本先用 `escapeSlashText`
- 成功后给 `/echo` 反馈
- 需要 AI 继续回复时再使用 `/send ... | /trigger`
- 失败时给出明确错误提示

#### 八、QR 的定位
QR 适合通过triggerSlash桥接作为入口、召唤器或快捷按钮。

QR 可以做：
- 一键要求 AI 输出某类特定回复
- 一键用 `/sendas name=\{\{char}\}` 插入可被正则捕获的角色楼层
- 一键调用其他 QR
- 一键触发后续剧情
QR指令需进行转义：如：
- 宏命令：输出 `\{\{char\}\}`，不要直接输出 `{{char}}`
- 闭包界：输出 `\{:` 和 `:\}`
- 管道符：输出 `\|`，不要直接输出 `|`

示例思路：

1. 数据展示页：AI 已经输出结构化数据，前端负责渲染。

```stscript
/send 请结算当前案件，并按案件结算模块输出。 | /trigger
```

2. 表单入口页：不需要 AI 先输出模块结构数据/生成世界书规范，只用空标签召唤前端表单进行填写。

```stscript
/sendas name==\{\{char\}\} <menu></menu>
```

对应正则：

```regex
/<menu>\s*<\/menu>/gi
```

表单提交后，由前端 JS 拼出触发词和用户填写内容：

```js
triggerSlash('/send ' + escapeSlashText(promptText) + ' | /trigger');
```

这类适合事件生成器、资料填写表单、选择确认页、开局配置器。

须区分“给用户复制的脚本”和“正则替换后实际运行的代码”。

1. 交付给用户复制的 QR/STscript：要进行转义。

```stscript
/sendas name=\{\{char\}\} 内容 \| /trigger
```

2. 正则替换代码里的 `triggerSlash`：按真实执行内容书写。

如果要让酒馆识别宏，写：

```js
triggerSlash('/sendas name=\{\{char\}\} 内容| /trigger');
```

3. JS 拼接用户输入或 AI 文本时，只转义“变量内容”，不要转义整条命令。

正确思路：

```js
const safeText = escapeSlashText(userText);
triggerSlash('/sendas name=\{\{char\}\} ' + safeText + ' | /trigger');
```

这里：
- `/sendas name=\{\{char\}\}` 是命令结构，保留真实宏
- `safeText` 是外部文本，需要转义
- `| /trigger` 是命令管道，保留真实管道

#### 十、运行时文本转义

当 JS 通过 `triggerSlash()` 拼接 `/send`、`/sendas`、`/echo` 等命令时，如果消息内容来自用户输入、AI 文本或世界书内容，应先转义消息内容中的特殊符号。

原因：
- `|` 可能被误解析为命令管道
- `{}` 可能被误解析为宏或闭包符号
- `\` 本身需要保护

推荐普通文本转义：

```js
function escapeSlashText(text) {
  return String(text ?? '')
    .replace(/\\/g, '\\\\')
    .replace(/\|/g, '\\|')
    .replace(/\{/g, '\\{')
    .replace(/\}/g, '\\}');
}
```

JSON 内容注意：
如果要传递严格 JSON 对象，不要转义 JSON 结构用的大括号。
这类场景通常只处理反斜杠和管道符，避免破坏 JSON。

```js
function escapeSlashJson(text) {
  return String(text ?? '')
    .replace(/\\/g, '\\\\')
    .replace(/\|/g, '\\|');
}
```

以上函数是推荐封装，不是酒馆命令本体。
底层依据是 STscript 对管道符、宏符号和闭包符号的解析规则。

按钮交互应检查 `triggerSlash` 是否存在。
